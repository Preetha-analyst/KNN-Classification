## Dataset

## Procedure
1. Loaded the Iris dataset.
2. Split the data into training and testing sets.
3. Normalized the features using StandardScaler.
4. Implemented the K-Nearest Neighbors (KNN) classifier.
5. Tested different values of K ranging from 1 to 10.
6. Evaluated the model using Accuracy and Confusion Matrix.
